# Shopping CMS API

This is the backend API for the Shopping CMS, built with ASP.NET Core.

## Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (or whichever version is used)
- SQL Server or preferred database

## Getting Started

1. Clone the repository.
2. Navigate to the `backend` folder.
3. Update the connection string in `appsettings.json` or `appsettings.Development.json` if necessary.
4. Run migrations: `dotnet ef database update`
5. Run the project: `dotnet run`

## Structure

- `backend/`: Contains the ASP.NET Core API project.
